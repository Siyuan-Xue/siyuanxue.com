# LeDA 智能体正式图集（2026-10-11）

## 来源与内容边界

用户确认项目名为 LeDA 智能体 / LeDA Agent，与现有条目及所附结题证书一致。2025 年 7–8 月与室友共同参与北邮大创项目，基于 LangGraph 构建知识图谱 RAG Agent，把 Awesome 开发者资源整理为 Neo4j 图数据库；具备资源检索与链接返回、提问历史和意图持久化、长期个性化学习资源推荐。80,000 余个资源节点由用户提供，不把视频某一帧当作数据库规模测量。

证书确认项目级别为国家级，薛思远是项目组成员，2026 年 7 月结题；没有改写成个人负责人、全国竞赛奖项或个人独立完成。公开正文保留与朋友合作完成项目的感受。资料链接为 [北邮项目主页](https://win.bupt.edu.cn/program.do?id=9909) 与 [Awesome 仓库](https://github.com/sindresorhus/awesome)。本轮通过浏览工具读取 Awesome 资源分类；北邮页未返回可读内容，链接依用户提供和既有条目保留，项目级别以用户提供证书核对。未访问项目登录或提交任何表单。

## 实现与媒体

- 稳定地址 `/gallery/leda-agent/`，原首页位置保留；双语 `draft: false`、`preview: false`，正式内容替代四张抽象占位图，进入 sitemap 并允许索引。首页显示 2025–2026，具体开发与结题时间分别在正文和图注说明。
- 可选 `videoTitle` 与 `videoLayout` 扩展既有模板：LeDA 使用本地化标题和 `demos` 单列布局，播放器最大 480px，窄屏按正文缩小；默认 `comparison` 保持 B-Spline 三列 / 224px 的既有行为。配对器阻止两语言视频布局不一致。
- 原生视频带播放控件、行内播放、元数据预加载、真实预览帧与下载链接，不自动播放；图片保持 PhotoSwipe，视频不加入图片灯箱。核心正文、图注、资料链接、播放器直接输出 HTML，元信息包含两个 VideoObject。
- 两个 MP4 实测均为 1280×896、30fps，时长 81 秒与 38.5 秒。AVFoundation 从第一个视频 50 秒、第二个视频 30 秒提取真实推荐界面与图谱画面；未修改原视频内容或速度。首次公开日期为 2026-10-11。
- 本机 `media-local/originals/leda-agent/` 保存原件副本和实际录制帧；未移动、删除或整理用户原始文件。Git 只保存五个媒体 ID 对应的尺寸、摘要、地址及大小，不包含图片、视频、密码或源文件的私人路径。
- 16 个媒体文件共 15,756,266 字节由原生 SSH/rsync 直传服务器，服务器全部通过大小及 SHA-256 校验。所选清单摘要为 `5edffcf7cdf3a6b5469c419ca12c0835cf38af4b5016f0ac0763452644387eff`，快照 `/var/backups/siyuanxue-media/<摘要>/` 为同磁盘恢复快照，并非异地灾备。
