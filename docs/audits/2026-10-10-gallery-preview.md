# 2026-10-10 公开图集版式预览

用户在图集模板上线后明确要求「占位预览也要上线，我要看看大致效果」。此要求更新了 10 月 8 日仅本地预览的边界；当时示例 404 的验收记录仍保留其时间语义。

## 实现与边界

- 基线 `main@1ee81c7`，开工时工作区干净，远端没有额外提交；在 `codex/publish-gallery-preview` 按文件分工实现。
- 两域名均生成 `/gallery/layout-preview/`，沿用四张明确标注的抽象占位图及现有灯箱。中英文介绍去掉「仅供本地查看」措辞，保留不代表真实项目或经历的说明。
- `src/utils/galleries.ts` 将固定样例与正常图集分开选择：只有该 slug 允许生产预览，其余普通草稿仍需正常发布条件。首页显式排除样例，源 JSON 保留 `draft: true`。
- 预览页始终 `noindex`；`astro.config.mjs` 从 sitemap 排除该路径。没有将占位内容当作真实成果加入项目目录。
- 作者指南和维护总览同步当前约定；未改 10 月 8 日历史审计中的当时结果。

## 验证

- 先修改集成测试，在旧实现下得到预期失败：缺少生产预览页；再实现指定路径例外。
- `bun run check`：79 文件，0 errors / 0 warnings / 0 hints，TypeScript 通过。
- `bun run build`：两语言各 8 页，22 项产物测试、550 个断言通过；包括图片资源、预览 noindex、首页和 sitemap 排除。
- `bun run test`：97 项测试、379 个断言通过；`bun run test:gallery`：1 项真实构建集成测试、238 个断言通过，使用与生产一致的 Node 24。
- 图集集成测试使用单独的 `published-fixture` 验证真实发布，并保留 `unpublished-fixture` 验证其他草稿不出页。原 `layout-preview` 源文件不再被改成非草稿来模拟普通内容。
- 独立审查确认路由、首页筛选和 sitemap 的固定路径一致，没有发现阻断项。
