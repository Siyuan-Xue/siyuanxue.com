# 聊天动态过程、居中与主页顶栏修正

日期：2026-10-02。修正基线 `244b78c`，此前静态网站 release 为 `0eb5a406eafa23ce7d9525b271243a48460e9f1c`。这是对[首次无侧栏发布](2026-10-02-chat-main-only.md)的后续修正，不把首次验收当作本次结果。

## 需求与实际参考

用户指出前轮未真实发送 Claude 问题观察动态状态，且加号、输入文字、用户气泡与页脚对齐有问题；要求左上角始终与主页姓名、字号和位置一致。继续保留原 Baby 图标、主页字体/文字色/背景、无侧栏。用户随后明确禁止在 Claude 使用中文；之后不再向 Claude 输入中文。

本次通过 Browser/Computer Use 在 Safari 新建独立 Claude 测试对话，实际发送无敏感信息的问题，并另发英文长故事提示捕捉流式阶段。没有向已有私人对话追加消息，也不将私人对话、账号信息或截图提交到仓库。观察到：

- 新对话输入框为两层布局；第一条消息发送后立即改为底部单行输入框，发生在第一段正文出现之前。
- 等待与流式阶段仍可输入草稿，发送控件替换为停止控件。多行草稿发送后恢复单行。
- 新文字逐步淡入，生成进度标记持续到回复结束；输入框在等待、正文流入和结束阶段保持底部位置。
- 长草稿扩展为上层文本、下层图标；结束后恢复普通发送控件。

没有声称精确测得 Claude 动画的时长或缓动曲线；本站下沉采用 280ms、文本淡入采用 220ms，并支持系统减少动态效果。

## 根因与修正

- 原自建顶栏使用 14px 对话标题和全宽 16px 边距，与主页顶栏完全不同。现在从同一 `site.name` 读取本语言姓名，并直接共用 `.header`、`.container`、`.header-name` 和控制按钮的全局样式。发送/清空会话不会改变姓名。
- 原输入框 `align-items: flex-end`，38px 文本框与32px图标导致图标中心低3px。改为居中网格，单行50px外框内的文本框与加号/发送控件同轴；多行展开为两层，按钮同轴置于下层。尺寸判断固定以紧凑模式的可用宽度测量，避免扩展后换行变化反复切换。
- 输入与用户气泡保留主页字体，按 Newsreader/思源宋体的可见字形中心作2px/1px的垂直留白补偿，用户文本使用独立块行盒。
- 页脚原 `baseline` 使两组中心相差约6.39px；改为居中并共享18px行高。
- 首次发送时动画移动同一个输入区；输入框获得焦点，草稿保持可编辑；停止和发送控件使用独立节点。
- 使用已经安装的 Streamdown 动画，不新增依赖。英文按单词、中文按字符淡入，避免无空格中文段落的新增字符被当作旧单词。保留现有 GSAP 墨线标记，等待和流式期间均显示；结束后移除并显示复制/重试。
