# 悬停反馈速度与粘土色强调

日期：2026-10-08。代码基线 `752ce4a6039817eb0cab0198b485932dd3e5910c`；开工时 main 与 origin/main 一致、工作区干净，仅一个主工作树。以下保留本地迭代的时间顺序，生产发布另见末尾补记。

## 首轮需求与实现（80ms阶段）

用户反馈悬停响应慢、颜色变化不明显，最初选择保留80ms变色过渡，并明确指定Claude粘土色；同日后续明确要求取消80ms，所有悬停统一即时响应。下方前轮80ms验收保留为历史，当前结果见末尾补记。

- 共享颜色过渡从 200ms linear 改为 80ms ease-out。去掉姓名子元素对继承颜色的第二层过渡，父链接统一负责变色。
- 粘土色基准 `#d97757` 来自 [Anthropic 官方品牌指南](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md)。浅色交互文字使用较深的 `#a14f35`，深色使用 `#e59b7d`；浅/深悬停背景分别为 `#f1e2d9` / `#4a332c`。这是本站为文字可读性调整的色阶，不声称所有色阶都是官方色值。
- 首页、文章正文、目录、返回链接、顶栏图标与聊天控件共用交互色。列表下划线随文字变色，正文链接悬停/聚焦时加粗下划线。目录不再只靠透明度反馈。
- 聊天输入区原深色悬停背景与容器同色；现使用独立背景与图标色。禁用发送按钮保留禁用状态，停止按钮单独处理；聊天装饰色共用粘土色基准。
- 键盘可见焦点使用同一强调色和轮廓；鼠标点击不产生常驻焦点框。灯箱关闭控件也采用 80ms 粘土色反馈。
- 打印颜色覆盖新增 tokens，避免深色模式的浅色强调文字打印在白纸上。现有减少动态效果规则继续覆盖过渡。
