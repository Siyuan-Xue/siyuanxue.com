# LeDA 视频宽度与总标题调整（2026-10-11）

## 变更与边界

用户反馈两个视频比正文窄，且「功能演示与知识图谱」总标题多余。原因是 `demos` 布局另设了 480px 上限；本轮取消该上限，两个播放器与正文共用窄栏宽度，保持原比例。

LeDA 双语 JSON 将 `videoTitle` 显式设为 `null`，不显示视频区总标题；各视频标题、图注和下载链接保留。总标题隐藏时，各视频使用二级标题，视频区提供本地化 `aria-label`，不引用不存在的标题 ID。配对器阻止两语言对总标题的显示选择不一致。未填写该字段的图集仍显示默认标题，B-Spline 保留模拟器结果标题及原三列紧凑布局。

只修改模板、CSS、类型/校验、双语内容与对应测试；原视频、封面和证书地址不变，没有上传媒体、修改 Nginx/helper 或独立服务。作者指南记当前规则；[首次发布记录](2026-10-11-leda-gallery.md) 保留初版的 480px 历史验证。
