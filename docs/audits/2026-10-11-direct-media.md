## 实现与独立安装

- 原有 18 张栅格图（13,438,290 字节）复制至 Git 忽略的 `media-local/originals/`，本机摘要逐一核对。
- 原图、Sharp 生成的 AVIF/WebP 缩略图及自然比例 JPEG 分享封面，共 140 个内容寻址文件、17,247,338 字节，直传至服务器 `shared/media/`。仓库只保存 `src/data/media.json`；普通 HTML picture/图片链接和尺寸/alt/图注仍直接输出。没有 CI 下载图片或远程 Astro 图片处理。
- 原生 SSH 严格沿用已知主机公钥，认证仅经终端提示；密码不进入代码、文档、参数、临时凭据或 Git。管理员 `ubuntu` 与 CI `deploy` 职责分开。
- 上传器 rsync 暂存、可续传；安装器逐文件验证路径、类型、大小与 SHA-256，拒绝符号链接与同名内容冲突，追加且不清理旧媒体。准备视频采用磁盘副本和流式摘要，避免把整个大视频读入内存。视频上传能力不等于已有图集视频播放器。
- 真实媒体已安装并校验；初次清单 SHA 为 `a88a9ba04903a7eede2ae56ea200c55fa3d667fe08fe6065daa10a8d4a33c7e0`。服务器硬链接恢复快照为 `/var/backups/siyuanxue-media/<清单SHA>/`；同磁盘快照不等于异地灾备。本机保存原文件及完整上传文件。
- 实际两个 Nginx vhost 仅增加媒体路由，未整份替换模板。修改前备份 `/var/backups/siyuanxue-media-nginx-20261010T164421Z/`，`nginx -t` 通过后 reload；没有修改网站 release、聊天/Hermes/微信/记忆/模型配置。

## 验证与发布

新增媒体 ID/格式/路径/摘要校验、本机准备和安装幂等/错误/冲突测试，先见失败再实现。Nginx 新路由测试在服务器高端口隔离实例先因缺媒体路由失败，新增路由后通过；两语言媒体、隐藏/缺失 404、MIME/缓存、视频 206 Range、旧照片 410 和既有跳转均覆盖。

本机类型检查 85 文件无错误/警告/提示；107 项前端测试、7 项媒体 Python 测试、9 项传输测试、部署 shell 测试和双语构建/25 项产物检查、1 项真实临时项目双语图集构建均通过。前端隔离端口测试在沙箱内遇到 EPERM，放行本机测试端口后完整通过。服务器已有 Nginx 用高端口隔离实例完成路由测试，本机未额外安装 Nginx。

上传失败误报与不完整恢复快照增加失败→通过检查，远端安装失败必须返回非零，恢复快照验证已有文件、以临时目录完成后原子就位。完整首次上传及仅准备一个媒体 ID 的幂等直传均已在实际服务器验证；当前本机静态包约 13.36MB，相较上版 96.27MB 不再包含媒体负载。
