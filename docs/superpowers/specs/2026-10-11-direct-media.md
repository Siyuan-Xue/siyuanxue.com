# 图片与视频直连服务器

用户已授权：以后图片、视频通过直连服务器上传，GitHub 不维护这些二进制资源；项目两语言名称均为 `Pixel Done`，保留既有 slug 和实际 GitHub 仓库地址。

网页代码和文字仍通过现有 Actions 同时发布两语言。媒体存放在服务器 `shared/media/`，独立于 release，使用内容 SHA-256 文件名和一年缓存。仓库仅保存媒体 ID、地址、尺寸、格式、大小和摘要。缩略图在本机用已安装 Sharp 生成，不在 CI 下载或重复打包。图片原比例、产品布局、独立肖像灯箱和旧照片 410 保持现有行为。

新增准备、直传和校验安装命令；认证走原生 SSH 提示和严格 known_hosts，不保存密码。先上传并逐文件校验，再发布引用；重传和同名冲突安全处理。本机忽略目录保存素材和派生图，服务器媒体独立于网站回滚保留。当前 Git 取消跟踪媒体，不重写历史、不删除旧 release 资源或既有备份。

验收：错误 ID/文件路径/摘要被拒绝，双语构建不依赖媒体文件且产物不含图片视频，Nginx 两站媒体缓存/类型/Range/404、旧照片拒绝和域名路由正确，Actions 与两站目标 SHA 一致，图片和两个灯箱实际可用。更新维护指南与带日期审计。
