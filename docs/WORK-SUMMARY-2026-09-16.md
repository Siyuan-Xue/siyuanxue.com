## 网站架构、外观和交互最终保留了什么

1. **架构审核与简化**：保留 Astro + Markdown + TypeScript + 普通 CSS。删除重复正文、重复目录解析、旧语言同步脚本等冗余；统一翻译配对、日期、草稿和目录生成规则。Dario Amodei 官网作为视觉/内容参考，`GrantBirki/dario` 作为第三方项目参考，不把第三方仓库声称为官网的权威源码。见 [初始审核](audits/2026-09-11-initial-audit.md) 和 [整改记录](audits/2026-09-11-remediation.md)。
2. **按域名固定语言**：`xuesiyuan.com` 中文，`siyuanxue.com` 英文；两个 www 分别跳转自己的主域名。静态构建各自语言，语言按钮跳同篇译文，不被浏览器偏好覆盖。文章、SEO、RSS 和 sitemap 都跟随域名。
3. **阅读与性能**：响应式头像、本地字体和中文字库分片；完整照片交互按需加载；目录采用实际 Markdown 标题，移动目录有键盘焦点处理；保留 reduced-motion、打印和窄屏处理。没有为博客另换框架或引入 CMS。
4. **图标与主题**：语言/明暗按钮用 Lucide，无圆形边框、不加 underline；主题同步初次渲染、按钮、浏览器元信息与前进后退恢复。共享顶栏背景最终为 **70% 不透明度**，12px 模糊，文字图标不一起变透明；没有把桌面 Safari/Chrome 观察冒充全部手机验收。见 [主题记录](audits/2026-09-14-native-theme.md)，其中早期 82% 后被 `bc6bbe5` 改为 70%。
5. **肖像展开**：取消多次点击解锁；所有访客单击即可展开占位肖像，每次新页面默认折叠。较复杂的新相册/特效方案被否决后撤回，最终保留原有 CSS / PhotoSwipe / GSAP 路线，没有上线被否决方案。
6. **占位肖像**：经历多版后，最终使用雾蓝背景、抬手整理头发的抽象女性侧影；当前文件 `public/images/romantic-placeholder-blue-study.webp`，为将来的爱人照片预留位置，正常真实肖像保留。生成依据见 [最终图片记录](audits/2026-09-16-portrait-blue-study.md)。
7. **灯箱与提示**：两站灯箱可见文案统一保留英文，辅助访问名称按语言本地化；删除开启/关闭提示标语块，只保留必要错误反馈。原私密照片删除，旧地址在 Nginx 返回 410，回滚时也保留封禁。
